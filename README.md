# Quiz App Practice

React + TypeScript quiz app based on the provided QuestionComponent / QuizComponent example and whiteboard design.

## Features

- React `useState`
- `.map()` for questions, choices, and progress boxes
- 10 questions
- Green check for correct answers
- Red X for wrong answers
- Progress boxes from 1 to 10
- Start Quiz screen
- Final score screen
- Try Again button

## Run

Open the project folder in VS Code, then run:

```bash
npm install
npm run dev
```

Open the localhost address shown by Vite.
